# VisitsPakistan --- User Flows

## Destination Research → Lead

Google/AI/Search → destination → attractions → best-time guide →
itinerary → relevant packages → partner/product → Request Quote →
matched operators. Success: `quote_submit`.

## Family Discovery

Homepage/Search → Things To Do → destination → family filter → itinerary
→ product → WhatsApp/quote.

## Adventure Discovery

Adventure landing → trek/experience → difficulty/season/permit →
verified operators → tour → quote.

## Partner Onboarding

List Your Business → register → business details → locations/services →
registration/license → documents → declaration → submit → admin review →
verified/rejected.

## Product Publishing

Dashboard → new product → type → destination → duration → itinerary →
price → inclusions/exclusions → cancellation → media → validation →
moderation → publish.

## Lead/Quote

Traveler request → matching → selected partners → notification → lead
opened → quote → traveler comparison → accepted/declined.

## Editorial

Create/link canonical entity → copy → facts → sources → review → SEO QA
→ publish → search indexing → sitemap refresh.

## AI Later

Prompt → intent → trusted retrieval → grounded plan → entity
citations/cards → products → save/quote. Unsupported facts must not be
fabricated.
